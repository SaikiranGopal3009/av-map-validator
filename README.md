# AV Map Validator

A Python tool for validating and visualizing road and lane-centerline geometry used in autonomous-vehicle mapping workflows.

## Planned features

- Load lane-centerline geometry from GeoJSON
- Validate geometry quality and continuity
- Calculate map metrics such as centerline length
- Visualize map features
- Export a machine-readable validation report

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
```
